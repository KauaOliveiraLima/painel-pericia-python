
# 🟢 Painel de Controle de Perícia 🕵️‍♂️ 

## Um sistema de terminal dinâmico desenvolvido em Python para simular um painel de gerenciamento de agentes de perícia e banco de dados de evidências criminais.

---

## 🚀 Funcionalidades

- **Efeito Typewriter:** Textos exibidos com efeito de digitação realista no terminal para maior imersão.
- **Navegação Dinâmica:** Sistema de loops que permite ao usuário navegar livremente entre diferentes painéis e retornar ao menu principal.
- **Validação Inteligente de ID:** Sistema que impede o cadastro de IDs inválidas, exigindo que o registro contenha exatamente 4 dígitos numéricos.
- **Estrutura de Dados em Memória:** Armazenamento organizado utilizando listas e dicionários para manipulação de dados em tempo real.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- Biblioteca `time` (para controle de fluxo e delays de animação)
- Biblioteca `sys` (para controle do buffer de saída do terminal)

---
